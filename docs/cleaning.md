# Pre-process ⚙️
Real Data have formating, noise, outliers and whole lot of complications
we have to streamline and structure the way up for making things easy.

### Required Steps 🔖
we would need a schema document to define the structure of dataset to process,
which we can use as references for validation, cleaning and formating of dataset

1. validation 
2. cleaning
3. removal of outlier
4. writing into clean streams

We can process these steps into chunking, run into a directory of dataset for streaming clean chunks which could be enumirated for processing through pythonic handlers. 🐼
