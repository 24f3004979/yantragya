## Some usefull starting topics to know 📖

we have used numpy, matplotlib and pandas, you may reffer to there official documentation for more detailed workflow with these tool, since they lift too many dependency in this project component thus good peices of things to pick up along the way

pandas 🐼 : data handling unit
    Loading dataset, and making good sense about the structure in a broad sense
matplotlib 📈: visualization library which gives up plot with few declarative lines with given input sets

numpy 🔢: Computational core an pythonic wrapper of optimized c version of numerical computations used in a good way into core algorithm implementations
